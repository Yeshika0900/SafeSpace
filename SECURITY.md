# Reporting security issues

Do not include room imagery, real device identifiers, exported inspection records or credentials in a public issue. Use a private GitHub vulnerability report if the repository offers that option; otherwise contact the repository maintainer through an established private channel before disclosing sensitive details. This document does not invent a contact address or promise a response time.

The helper's Origin/Host/custom-header controls reduce hostile browser access, not arbitrary local-process access. It must stay loopback-only. Storage and downloads remain under the browser/device's normal protections. Zero npm advisories or a passing secret scan is not a complete security assessment.
