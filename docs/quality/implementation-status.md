- Original baseline: Node 24.22.1, npm 11.9.0; root, website and helper `npm ci` passed. All original audits reported zero advisories; production build passed. React 18.3.1, Vite 6.4.5, TF.js 4.22.0, COCO-SSD 2.2.3, Capacitor 8.6.0, BLE plugin 8.3.0.

Lint/type/test checks and the audit validate this tool-only override. React/Vite/Capacitor/model runtime major versions are unchanged.

## Remaining limitations

Authorized physical Android/browser BLE/camera, actual phone/local-network permission policies, native APK/lint/tests/merged manifest, other browsers/screen readers, complete original model-training provenance and larger independent/phone evaluations remain unexecuted. The production upstream weight URL remains mutable; only benchmark retrieval is checksum-enforced. Legacy storage migration drops unnecessary metadata; previously downloaded files are outside app clearing, and unavailable device storage can prevent persistent migration/clearing (the UI reports it).

No new product features were added. Camera capture, browser/native BLE modes, local history/JSON export, IPv4 inventory and the existing checklist remain the four-tool product. No hidden-camera/tracker model, new collection settings, account, dashboard, pairing, extra export format, public helper endpoint, main merge or deployment was introduced.
