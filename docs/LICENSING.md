SafeSpace's original source code, documentation and original repository artwork are available under the [MIT license](../LICENSE). The npm manifests use the SPDX identifier `MIT`. This licensing choice was added on 14 November 2026 following the repository owner's request to license the project.

## What MIT permits

You may use, copy, modify and distribute the covered work, including commercially, provided you retain the copyright and permission notice in copies or substantial portions. MIT does not require you to publish modifications. The work is provided without warranty, with the liability limits stated in the license.

The license identifies the copyright holders collectively as **SafeSpace contributors**. It does not replace third-party copyright lines or claim ownership of external libraries, fonts, model checkpoints or datasets.

## What stays separate

- Installed libraries and generated native tooling keep their upstream licenses and notices.
- The DM Sans and Manrope fonts retain their SIL Open Font License terms.
- Separately downloaded model weights, COCO images, annotations and their metadata keep their source terms. A JavaScript package license is not a blanket license for checkpoint or dataset redistribution.
- Original SafeSpace report text, diagrams and brand artwork are covered by MIT; included third-party content is subject to its own terms.

[Third-party notices](../THIRD_PARTY_NOTICES.md) links the verified direct runtime packages, retained license texts, font notices and Gradle wrapper terms. Package lockfiles retain declared licenses for other dependencies. Artifact-specific notices must travel with a redistributed bundle or APK.

## Contributing and reuse

Unless an explicitly applicable file notice says otherwise, contributions intended for inclusion in SafeSpace are submitted under the same MIT terms. Preserve existing attribution and identify externally sourced material and its license. Reuse of the code does not imply endorsement by the project contributors or the upstream dependency authors.

For private user imagery, device metadata or downloaded inspection reports, the code license grants no rights to someone else's data. Use only material you are authorized to inspect or share.
